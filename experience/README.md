# Engineering Journey (3D Experience)

Scroll-driven cinematic 3D portfolio chapters for Flying Ibn Firnas.

## Stack

- Vite + React + TypeScript
- Three.js / React Three Fiber / Drei
- GSAP ScrollTrigger + Lenis

## Develop

```bash
cd experience
npm install
npm run dev -- --base /
```

Open http://127.0.0.1:5173/

## Build for GitHub Pages

```bash
npm run build
```

Outputs static files to `../journey/` (served at `https://flyingibnfirnas.com/journey/`).

Classic HTML portfolio pages remain at the site root.
